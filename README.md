# 兴庆漫游

以西安交通大学兴庆校区为背景的像素校园探索游戏，由临兵者发起，欢迎校友一起完善。由Netlify生成网页链接，可点击网页链接直接游玩：https://xjtuxq.netlify.app/

**这是源码公开、仅限非商业使用的分享版本。允许学习、修改和非商业分享；禁止商用和盈利。具体授权范围以 [LICENSE](LICENSE) 为准。** 含有非商业限制，因此不属于 OSI 定义的标准开源软件。

## 这个仓库包含什么

- 原生 HTML、CSS、JavaScript 和 Canvas 游戏代码，无需大型游戏引擎或构建工具。
- 男女角色选择、四向行走、人物及建筑的程序绘制。
- 八章主线、校园路人、多轮对话、可选支线和「临兵者」彩蛋。
- 建筑检索、地图缩放、路线引导、骑车与步行、手帐和收集系统。
- 季节、日夜、像素雨天效果，以及存档导入导出和重新开始入口。

以上是保留在代码里的功能。**本仓库不包含真实校园地图几何、地标坐标表、原始地图提取数据、地图照片、BGM 或雨声音频。** 校园名称、剧情文字、角色像素参数和界面绘制参数仍保留；这些不等于可还原校园的完整地图数据。

因此，克隆后不能直接游玩完整校园。未配置资源时，会显示明确的资源说明页，不会自动下载地图或播放声音。`examples/` 只给出接口结构，不是可玩的示例地图。

## 本地查看

在本目录打开终端，执行：

```powershell
python -m http.server 8767 --bind 127.0.0.1
```

浏览器打开 <http://127.0.0.1:8767/>。按 Ctrl+C 停止服务。如端口被占用，换一个端口，并相应修改地址。电脑网页端为当前维护目标，手机端不作为本次交付的验证目标。

仅查看源码和资源说明页，不需要任何地图或音频。要启动游戏，先阅读 [资源接入指南](docs/资源接入.md)，自行准备有权使用的地图和地标位置，再编辑 `source-settings.js`。不要直接把 `examples/` 的空结构配置成真实地图。

## 操作

配置完成后：WASD / 方向键移动，Shift 奔跑，E 互动，M 地图，J 手帐，T 剧情，Esc 关闭面板。R 切换雨天，N 切换日夜，Y 切换季节，F 使用附近摄影点；在单车点按 E 骑车，B 下车。

音乐和雨声为可选项，不配置也可以启动；程序生成的短促互动提示音仍保留，可在设置中关闭。音频播放由用户交互触发，受浏览器规则影响。

## 文件结构

| 文件 | 作用 |
| --- | --- |
| `index.html`、各 CSS 文件 | 界面结构与样式 |
| `source-settings.js` | 本地资源路径配置，默认全部为空 |
| `source-loader.js`、`source-package.css` | 资源检查、顺序加载与缺少资源时的说明页 |
| `content.js` | 地标介绍与主线定义，不含实际地标坐标表 |
| `sprites.js`、`architecture.js` | 角色与建筑绘制 |
| `game.js` | 场景、移动、碰撞、主线和基础游戏逻辑 |
| `features.js` | 天气、导航、角色选择、计时跑状态等扩展 |
| `encounters.js`、`campus-life.js` | 校园互动、支线、建筑检索、存档管理 |
| `people.js`、`exploration.js`、`conversations.js` | 路人、探索活动和连续对话 |
| `examples/` | 不含地图数据的接口示例 |
| `docs/` | 接入指南、上传步骤和本次验证记录 |

## 存档与隐私

进度保存在浏览器本地存储，不上传服务器。沿用原游戏的 `xingqing-osm-v2` 存档键，保留兼容逻辑；不要为了改外观而删除它。不同域名、端口或浏览器的存档彼此隔离，搬家前可用游戏里的导出/导入功能备份。更换地图布局时，旧存档的位置、建筑索引等可能需要单独迁移，不能承诺适用于任意地图。

请勿把自己的存档、下载文件、账号配置、密钥或原始资源提交到仓库。
