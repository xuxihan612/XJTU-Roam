# 资源接入指南

本指南解释现有游戏所需的资源接口。它不提供真实地图，也不自动联网采集或下载资源。示例字段中的 `null` 必须由接入者用有权使用的数据替换；空示例不会启动完整游戏。

## 1. 本地文件与配置

在仓库根目录自行建立 `private/`，放入本地地图及地标位置脚本。若需音频，可一并放入，但这些文件不随此仓库发布。编辑 `source-settings.js`：

```js
window.XQ_SOURCE_CONFIG = {
  mapScript: 'private/campus-data.js',
  positionsScript: 'private/landmark-positions.js',
  bgmSrc: null,
  rainSrc: null
};
```

路径相对网站根目录中的 `index.html`，使用 `/`。不要填写本机磁盘路径。两个地图相关脚本需要分别定义 `window.CAMPUS` 和 `window.CAMPUS_LANDMARKS`；若地图脚本已有 `CAMPUS.landmarks`，`positionsScript` 可以设为 `null`。

这些脚本会作为 JavaScript 执行，因此只接入可信且有权使用的文件。`private/` 只是 Git 忽略目录的名字，不是访问保护；如果把它上传到公开网站，访客就可能下载其中的资源。

资源说明页不是资源浏览器，也不会让玩家上传地图。修改配置后刷新页面；遇到无法读取、字段缺失或初始化错误，会保留说明页并提示检查。

## 2. 地图对象

`examples/map-interface.example.js` 给出空结构。当前代码的契约：

| 字段 | 要求 |
| --- | --- |
| `W`、`H` | 正数，地图像素宽高；原剧情的距离显示沿用 2 像素约 1 米的约定 |
| `source` | 来源与许可的文字说明；接入者仍须在界面完成适用署名 |
| `wall` | 有限数字 `x0,y0,x1,y1`，分别为矩形边界；小值在前 |
| `buildings` | 建筑多边形数组；`n` 为名称，`s` 为外观类型，`lv` 为正数楼层，`p` 为顶点数组 |
| `roads` | 道路数组；`n` 名称、`k` 类型、正数宽度 `w`、折线顶点 `p` |
| `streets` | 校外/边缘道路数组；至少包含有效折线 `p`，不使用时为空数组 |
| `pitches` | 运动场多边形数组，含 `n,p`；剧情至少要求一处名称含“田径”的运动场 |
| `parks,water,woods` | 公园、水体、林地多边形数组，含 `p`，不使用时为空数组 |
| `gates` | 校门数组，每项有 `n,x,y,side`；`side` 为 `n/s/e/w`，至少两项，第二项必须是南门 |
| `plaza` | 广场顶点数组，直接使用 `[[x,y], ...]`，不是 `{p:...}` |
| `pois.tengfei` | 腾飞塔位置 `{x,y}`，必须提供 |
| `pois.westGarden` | 可选的西花园标签位置 `{x,y}` |
| `nameNotes` | 可选名称补充表，键为 `buildings` 的数组索引，值如 `{name:'待补充名称'}`；应先核实名称 |
| `landmarks` | 可选地标坐标表，可替代独立的位置脚本 |

坐标为左上角原点、x 向右、y 向下的地图平面像素，不是经纬度。多边形至少三个有限顶点；折线至少两个有限顶点。所有内容应落在合理的地图范围，不能用 `null`、字符串数字或 `NaN` 代替。代码会计算多边形的包围盒和中心，不必预填 `cx,cy,x0` 等派生字段。

支持的建筑外观 `s`：`redroof,dorm,library,maintower,mainwing,activity,gym,memorial,canteen,glass,hospital,commercial,utility,modern`。楼层 `lv` 要提供有效值。未知风格不会自动变为可绘制素材。

至少一条道路的 `k` 为 `unclassified` 或 `service`，供路人和设施使用。道路类型还可用 `path`、`track`。为兼容原梧桐叶玩法，至少一条有效道路名称需包含“梧桐”“文治”或“学森”。这些条件来自当前代码，不是通用地图引擎接口。

每项为 `{x: 有限数字, y: 有限数字}`。应选择靠近入口且可到达的地面位置，不能位于建筑、水体或围墙内。加载时会尝试吸附到附近可走区域，但它不能修复任意错误的地图；如附近没有通路，仍须调整资源。

游戏保留了与兴庆校园相关的名称匹配、距离约定、剧情和装饰规则，所以不能保证任意别的学校地图直接兼容。请验证主要入口、支线、运动场和收集点的位置，地图变化较大时还需相应修改玩法。

## 4. 可选音频

有权使用的文件准备好后，将 `bgmSrc` 和/或 `rainSrc` 改为相对路径，例如 `private/music.mp3`、`private/rain.ogg`。不设置时音乐或雨声控制会禁用，不应请求不存在的音频文件。晴雨画面切换仍可以使用。

浏览器要求用户交互后才允许音频播放；先选择角色并进入游戏，再检查开关与音量。音频也需要服务器提供正确类型，不要把本机路径或第三方临时下载链接作为公开部署资源。音乐与雨声音轨分别循环，不要在修改时重复创建播放实例。

程序生成的短促互动提示音不依赖外部音频文件；如需要完全静音，在设置中关闭互动音效。

## 5. 启动与常见问题

使用 README 中的本地 HTTP 命令；直接双击 HTML 的文件模式不作为支持方式。

- 仍显示“此源码包未附地图资源”：检查 `mapScript` 是否配置并保存；默认 `null` 就是此行为。
- 提示无法加载：检查相对路径、文件名大小写、服务器根目录及浏览器网络面板。
- 提示地标不完整：补齐全部二十个 ID，或检查 `positionsScript` 是否被正确加载。
- 场景初始化失败：检查道路、顶点、建筑外观、楼层、校门顺序及浏览器控制台。
- 人物卡住/路线不通：调整入口和碰撞资源；不要关闭全局碰撞来掩盖问题。
- 角色进度消失：确认是否换了端口、域名或浏览器；本地存储按站点隔离。必要时导入备份。

## 6. 上传边界

公开源码时保持 `source-settings.js` 默认空配置，只上传这份干净源码目录。`.gitignore` 不会过滤 GitHub 网页拖拽上传，也不能让已提交到历史的私有资料消失。

如要公开可玩版本，请另外准备获准公开使用的资源和必要署名，并检查音乐及地图条款。这一步与发布纯源码不同。不要把原始完整版部署 ZIP 当作本源码仓库的 Release 附件。
